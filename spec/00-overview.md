# 00. プロダクト概要 — calm-cascade

## ビジョン

**「操作するたびに心がほどける、瞑想のようなマッチ3」**

calm-cascade は、癒しに全振りしたプレミアム 2D マッチ3 パズル Web ゲーム。
タイマーなし・ゲームオーバーなし・ノルマなし。プレイヤーを急かす要素を一切排除し、
宝石が消え、落ち、連鎖する様子そのものが報酬になる「ジューシーで静かな」体験を提供する。

## ターゲットユーザー

- **普段ゲームをしない人**。チュートリアルを読まなくても 10 秒で遊び方が分かること
- **スマートフォンで片手操作する人**。通勤中・就寝前・待ち時間に、親指 1 本で完結すること
- 反射神経・スピードを要求されるゲームが苦手な人。**失敗という概念がない**こと

## デザインピラー（すべての意思決定の判断基準）

| ピラー | 意味 | 具体例 |
|---|---|---|
| **Calm（癒し）** | プレイヤーを急かさない・罰しない | タイマーなし、ゲームオーバーなし、有効手がなければ無言でリシャッフル |
| **Juicy（ジューシー）** | 操作への応答が気持ちいい | 連鎖のコンボテキスト、パーティクル、控えめな画面シェイク、柔らかいバウンド |
| **One-Handed（片手完結）** | 親指の可動域だけで全操作 | ボトムヘビーレイアウト、44px 以上のタッチターゲット、スワイプ/タップ両対応 |
| **Premium（上質）** | 細部の品質が体験を作る | Retina 対応のシャープな Canvas、60fps、グラスモーフィズム HUD、ダーク/ライトテーマ |
| **Inclusive（誰でも）** | 身体特性で遊べない人を作らない | prefers-reduced-motion 尊重、色覚多様性対応（形状差別化）、a11y 対応 UI |

## ゲームの骨子

- 8x8 グリッドのマッチ3。隣接する宝石をスワップし、3 個以上並べて消す
- 消えた宝石は上から落下・補充され、**連鎖（カスケード）** が発生する
- 4 個マッチで **レーザーピース** が生成され、行/列を一掃する爽快ギミック
- スコアとコンボは記録されるが、比較・競争の要素はない。自分の統計だけが積み上がる

詳細ルールは [01-game-design.md](./01-game-design.md) を参照。

## スコープ

### 今回のスコープ内

- マッチ3 コアループ（マッチ検出・カスケード・スポーン）一式
- スワイプ / タップタップ両対応のタッチ操作
- レーザーピース（横4→行消し、縦4→列消し、チェーン発火）
- コンボテキスト（DOM オーバーレイ）・パーティクル・画面シェイク・ビーム演出
- グラスモーフィズム HUD、設定/遊び方 Dialog、統計 Tabs、ダーク/ライトテーマ
- **拡張 4 点（ユーザー承認済み）**:
  1. 設定・統計の localStorage 永続化
  2. ハプティクス（navigator.vibrate、設定でオフ可）
  3. 色覚多様性対応（宝石を色 + 形状で区別）
  4. Web Audio によるシンセ生成の効果音・環境音（設定でオフ可）

### スコープ外（将来構想）

- 5 個マッチ・L/T 字マッチ専用の追加特殊ピース（爆弾・全消し等）
- ステージ / レベル / ミッション制
- オンラインランキング・ソーシャル要素
- PWA 化（オフライン対応・ホーム画面追加）
- 多言語対応（UI テキストは当面英語表記の装飾的テキストのみ）
